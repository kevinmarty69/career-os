# Agentic stack benchmark

Verified against official repositories and documentation on 2026-09-02. This is an engineering license screen, not legal advice.

## Elimination criteria

Every component was checked for exact core/enterprise licensing, commercial managed-SaaS use, functional self-hosting, TypeScript fit, tenant isolation, durable resume, HITL, quotas, exportable tracing, security maturity, lock-in, operational cost and code it actually removes.

Permissive MIT/Apache-2.0 libraries can be included in this AGPL-3.0 product with their notices preserved. AGPL software can be used commercially; redistribution and modified network deployments carry corresponding-source duties. A separate HTTP service is not automatically a derivative work. Enterprise folders and hosted-service terms are separate gates.

## 5. Sandboxes, browsing and extraction

Agents receive no shell by default. Offer text paste is the guaranteed path; URL extraction begins with a bounded HTTP fetcher that revalidates DNS and every redirect, blocks loopback/private/link-local/metadata IPv4 and IPv6, restricts ports/MIME/bytes/time and runs behind an egress policy.

## Recommended stacks

### Minimal selected stack

- Next.js + Zod + PostgreSQL/Supabase RLS.
- Explicit versioned state machine, artifact ledger and server-enforced budgets in Postgres.
- One direct structured-output provider SDK when generation becomes real; BYOK/local OpenAI-compatible endpoint for self-host.
- OpenTelemetry export boundary when model calls land.
- Plain SSRF-safe HTTP extraction first; no shell.
- Rootless Docker + Playwright only as a measured fallback.

This avoids adding any agent framework, proxy, trace dashboard or workflow service before it removes real production code.

### Alternative at scale

- Temporal for durable multi-day workflows.
- OpenAI Agents SDK TS or Mastra core-only for bounded tool/handoff behavior if direct calls become inadequate.
- Langfuse core as an optional isolated observability profile.
- Envoy AI Gateway for Kubernetes-scale routing and quotas.
- Per-run sandbox workers; Hermes remains a dedicated single-tenant self-host option.

## Rejected or deferred

- Rejected now: CrewAI, LiteLLM, shared Hermes, E2B, Trigger.dev as the OSS durability contract.
- Deferred: Mastra, OpenAI Agents SDK, LangGraph, Temporal, Langfuse, Envoy AI Gateway, Firecrawl Cloud/self-host, Playwright worker.
- Explicitly excluded: Mastra `ee/`, LiteLLM `enterprise/`, Langfuse `ee/`, proprietary LangSmith/hosted gateway behavior as a required self-host dependency.
