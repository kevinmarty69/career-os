# Milestone - le nouveau front devient la base produit

Career OS utilise désormais un seul langage d'interface pour l'accueil, la mémoire professionnelle, les candidatures, les arbitrages et les dossiers.

Le front historique reste hors du parcours visible. La suite du MVP avancé sera branchée sur cette base, lot par lot, sans réintroduire une seconde interface.
